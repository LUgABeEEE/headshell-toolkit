# 架构

```
                  参数（你自己给，params/schema.example.json 是字段全集）
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        ▼                           ▼                           ▼
    core/fit/                  core/print/                  core/geometry.py
  测量 / 关键点 / 内模        外壳、开孔、通风、间隙、归一化    布尔与网格工具
        │                           │                           │
        └───────────────────────────┴───────────────────────────┘
                                    │
                              pipeline/
                 契约 · 断点续跑 · 量化阈值（数值留空）
                                    │
                     cli/  ·  blender/  ·  adapters/
                 命令行、无头 Blender 驱动、外部输入适配
                                    │
                               tools/
              独立小工具：STL 体检 · 四视角渲染 · 效果图 · 连通体审计
```

## 边界

- `core/`、`pipeline/`、`cli/`、`adapters/`、`tools/` 为本项目自有实现，按 MIT 发布。
- 不包含任何第三方几何资产；对第三方实现的参考只停在「行为」层，不复制代码、节点图或网格。
- 参数取值不属于本仓库：契约只固定字段与含义，具体数值由使用者提供。
- Blender 作为工具被调用（GPL-2.0+），本仓库不链接其代码；脚本产物归属使用者。
