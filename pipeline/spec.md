## 0. 范围与独立性（必读）

1. **本契约不依赖前脸任务**。S0–S3 的全部定义、检查与门禁只依赖本仓库内的壳体网格与本地工具；`face/`、`<base-model>` 的任何产物都不进入本契约的判定依据。

3. 本任务只产出 `pipeline/spec.md`（本文）与 `pipeline/metrics.json`；fixture 与前脸目录为只读/越权禁区。
4. 单位一律 mm；三角网格；检查命令全部在 `<workspace>/headshell` 下执行。

## 2. 阶段步骤与门禁

### S0 清洁（clean）

1. 读入 → 单位/朝向校验（bbox 合理、脸在 +Y、Z 向上）；
2. 法线一致化（image-to-3D 绕向不可信，必须 `normals_make_consistent` 等价处理）；
3. 顶点焊接（容差 1e-4mm）→ 去退化三角（面积 < 1e-9 mm²）；
4. 去碎体：保留最大连通体（有意的独立件如格栅除外，逐一记录）；
5. 输出 manifest。

**门禁**：C2（watertight / boundary / nonmanifold / degenerate）。输入本身就非水密时，S0 必须修复到水密或 fail，不带病下行。

### S1 抽壳 3mm（shell）

1. 目标壁厚 **`<wall_target>`**（取值不公开）（SOLIDIFY 或内偏移；外表面保持不变，向内抽）；
2. **先切后抽壳原则**：眼/嘴/通风等开孔如能安排在抽壳前（实心阶段）完成，优先该顺序；抽壳后开孔必须走 §5 的受控切割；
3. 抽壳前法线一致化（见 S0.2），抽壳后全量复检。

**门禁**：C1（壁厚）+ C2（水密）。

### S2 40 三角通风孔（vents）

character-a与切刀规则见 §3.2；产出 `grid.json`。

**门禁**：C3（全部孔贯穿 + 全部角点/环闭合）+ C1 + C2。

### S3 竖向分件 + 平滑法兰（尺寸见私有参数）（split + flange）

分件面与法兰定义见 §3.3/§3.4。

**门禁**：每件独立过 C4（法兰）+ C1（壁厚）+ C2（水密）。

## 3. character-a定义（冻结参数）

### 3.1 抽壳壁厚

- 名义 **3.0mm**；壁厚中位 2.85–3.15mm；p05 ≥ 2.2mm（阈值表见 `metrics.json → wall.thresholds`）。
- 2V/A 平均壁厚 2.7–3.15mm 作交叉校验。

### 3.2 三角通风孔（40 个）

| 参数 | 冻结值 |
|---|---|
| 数量 | **40**（8 列 × 5 行） |
| 形状 | 等边三角形，**边长 10.0mm ±0.3**（单孔面积 43.3mm²，总开口 1732mm² ≈ 旧 Ø6×48 方案的 1.28 倍） |
| 列位 x | −70, −50, −30, −10, 10, 30, 50, 70（列距 20mm） |
| 行位 z | 12, 34, 56, 78, 100（行距 22mm） |
| 区域 | 后脑（−Y 侧），孔心落在后脑曲面上 |
| 朝向 | 相邻行尖端方向相反（奇数行尖朝 +Z，偶数行尖朝 −Z） |
| 切刀 | 三棱柱沿孔位**局部表面法线**；长度 = 局部双壁厚 + 两侧各 2mm 余量；必须贯穿近侧双壁（防盲袋）；越过近侧内壁伸入内腔 **≤ 2mm**（防内伸切刀），严禁触碰远侧壁 |
| 贯通定义 | 孔轴射线自外部打入：首命中落在孔心平面之外（= 穿过近侧壁进入内腔后才命中远侧壁）|

### 3.3 竖向分件

- 分件面：**竖直面（含 Z 轴），法向 ±Y，位置 y = 0（耳线）**；切面必须竖直，不允许斜切或阶梯切（阶梯仅出现在法兰唇上）。
- 产出：`shell_front.stl`（y ≥ 0，前脸件）与 `shell_back.stl`（y ≤ 0，后壳件）。
- 两件各自独立满足 C1/C2/C4；装配贴合面间隙 0–0.3mm。

### 3.4 法兰（8×2mm 平滑）

| 参数 | 冻结值 |
|---|---|
| 唇宽（径向，分件面内沿截线外法向） | **8.0mm** |
| 唇厚（沿 ±Y） | **2.0mm**（每侧各一片，贴合面对贴） |
| 贴合间隙 | 0–0.3mm |
| 光顺 | 法兰由**光顺截线**（低通/样条）驱动生成；禁止直接沿三角化边放样（→ 锯齿法兰） |
| 径向偏差门限 | 相对 8.0mm：p95 ≤ **0.5mm**，max ≤ **1.2mm**；相邻测点宽度抖动 p95 ≤ **0.3mm** |
| 唇厚门限 | 2.0 ± 0.3mm |

## 4. 检查方法与阈值

命令原文在 `pipeline/metrics.json` 的对应 `*.command` 字段；执行方式：

```bash
cd headshell   # 从工作区根进入
python3 - <<'PY'
import json, subprocess
d = json.load(open('pipeline/metrics.json'))
subprocess.run(['bash', '-c', d['wall']['command']])        # C1
subprocess.run(['bash', '-c', d['watertight']['command']])  # C2
subprocess.run(['bash', '-c', d['vents']['command']])       # C3 scan
subprocess.run(['bash', '-c', d['flange']['command']])      # C4
PY
```

### 4.1 C1 壁厚（wall）

- **方法**：表面均匀采样 6000 点（种子 0），沿**内向法线**（-normal，起点内偏 1e-3mm）打射线，Möller–Trumbore 精确求交（三角形质心 KD-tree 取候选），**首命中距离 = 局部壁厚**。
- **阈值**：中位 2.85–3.15mm；p05 ≥ 2.2mm；2V/A 均值 2.7–3.15mm；miss + 退化（<0.05mm）样本占比 ≤ 1%。min 值仅记录不设门（尖角掠射会产生单点极小值）。
- **验证**：60mm/54mm 封闭中空立方体（真值 3.000mm）→ 实测中位/p05 = 2.999mm。

### 4.2 C2 水密（watertight）

- **方法**：边使用计数 + 绕向一致性 + 连通体 + 欧拉示性数 + 退化三角。
- **阈值**：`watertight=true`、`boundary_edges=0`、`nonmanifold_edges=0`、`winding_consistent=true`、`degenerate_faces=0`。
- **验证**：立方体 pass；删 1 三角的立方体 → `boundary_edges=3` 正确 fail。

### 4.3 C3 通风孔射线检测（vents）

- **方法**：沿孔轴射线（轴 = 孔位局部法线），按首命中分类：
  - 命中点在探针面**之外** → `open`（贯穿）；
  - 探针面**之前** → `closed`（盲袋/未贯穿）；
  - 无命中 → `no_hit`（探针脱靶，按失败计）。
- **探针character-a**（每孔 7 条）：孔心 1 条；三角 3 个顶点向内收 **1.0mm** 各 1 条（应 open）；3 条边中点向外偏 **1.5mm** 各 1 条（应 closed，验证孔径未放大）。
- **阈值**：`open_center 40/40`、`corners_open 120/120`、`ring_closed 120/120`；孔径边长 10.0 ±0.3mm（由角点/环探针等效验证）。
- **扫描模式**（`scan`）：按 10mm 网格扫后脑区域，报告 open/closed/no_hit 探针数与 open 点位——用于基线记录与"开口出现在名义孔区之外"（内伸切刀）的排查。
- **验证**：`out/m1b/shell_full.stl` 的 48 个 Ø6 真实贯穿孔 → 48/48、144/144、144/144 全部正确判定。

### 4.4 C4 法兰径向偏差（flange）

- **方法**：取分件件上 |n_y| ≥ 0.95 且位于分件面附近的贴合面（按 y 平面分组），对每片环带取内外边界环并1mm 重采样；外缘点到内缘的最近距离 = 径向宽度 `w`；`radial_dev = |w − 8.0|`；相邻外缘点（≈1mm 间隔）的 |Δw| = 抖动（锯齿指标）。唇厚 = 贴合面 y 极值到分件面的距离。
- **同时报告**：分件面截线（`seam_section`）的环带宽度/抖动/波动——法兰由该截线生成，截线抖动即锯齿法兰根因。
- **阈值**：`radial_dev p95 ≤ 0.5mm`、`max ≤ 1.2mm`、`jitter p95 ≤ 0.3mm`、唇厚 2.0 ±0.3mm。
- **验证**：8.0mm×2.0mm 合格环带 → 宽度 8.0、偏差 0、抖动 0（pass）；外缘 ±0.8mm 锯齿环带 → 偏差 0.8、抖动 0.822（正确 fail）。

### 4.5 辅助工具（不替代 C1–C4）

`python3 scripts/verify_print_m1b.py <stl> --json <out.json>`：补充拓扑/开口清单/0.2mm 分层扫掠，作为旁证。

## 5. 失败模式与门禁映射

### 5.1 薄壳布尔（thin-shell boolean）

- **症状**：布尔切割/合并直接作用于 3mm 薄壁后留下碎面、非流形边、局部壁厚塌陷（p05 骤降）、零面积三角、内腔残片。
- **检测**：C2（boundary/nonmanifold/degenerate/bodies）+ C1（p05、miss 率）。
- **预防**：能先切后抽壳就先切；必须在薄壳上开孔时用 EXACT 求解器 + 切前备份 + 切后局部修复；每刀之后全量复检 C1/C2。
- **处置**：任一指标超标 → fail，回滚到上一步重做，禁止带病下行。

### 5.2 内伸切刀（inward-protruding cutter）

- **症状**：切刀越过近侧内壁伸入内腔，削伤远侧壁/内壁，或盲切变贯穿、贯穿变盲袋；内腔留碎体。
- **检测**：C3 扫描模式的 `open_points_xz` 落在名义孔区之外；C1 局部异常薄点/miss 聚集；C2 `bodies` 出现新增连通体。
- **预防**：切刀长度按 §3.2 公式（局部双壁厚 + 2mm 余量）逐孔计算，禁止固定深度长刀；非贯穿特征的刀体越过内壁 ≤ 2mm。
- **处置**：检出即 fail，修切刀参数重切。

### 5.3 锯齿法兰（jagged flange）

- **症状**：法兰随三角化接缝呈锯齿，贴合面有缝、装配错位、边缘毛糙。
- **检测**：C4 `radial_dev_p95 > 0.5mm` 或 `jitter_p95 > 0.3mm`（含 `seam_section.band_jitter_p95`）。
- **预防**：法兰由光顺截线（低通/样条）驱动生成，禁止直接沿三角化边放样；分件面前对截线做 0.3mm 级平滑。
- **处置**：超限即 fail，重建法兰后复检 C4。
